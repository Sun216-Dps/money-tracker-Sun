# 记账本 V1.1

个人记账应用：网页版 + Android APK 工程。纯前端、无后端、无第三方依赖，数据保存在本机。

## 功能

- **记账**：金额、日期时间、类型（收入/支出）、备注、资金来源、记账人；支持新增 / 编辑 / 删除
- **分类管理**：支出分类、收入分类可自定义增删改；资金来源、记账人同样可管理
- **统计可视化**：本周 / 本月 / 本年切换，收支柱状图 + 分类占比环形图 + 收入/支出/结余汇总
- **Excel 导入导出**：导出 `.xlsx`；导入 `.xlsx` / `.csv`（列名自动识别、分类/来源/记账人缺失时自动补建）
- **数据管理**：JSON 备份导出/导入、清空重置
- **离线可用**：无网络也正常工作（localStorage 持久化）
- **浅色 / 深色主题**：默认浅色，右上角按钮一键切换，选择会记住

## 目录

```
money-tracker/
├── index.html        页面结构
├── style.css         样式
├── app.js            业务逻辑（数据、渲染、增删改、统计、导入导出）
├── xlsx-lite.js      极简 xlsx 读写（ZIP + OOXML，自行实现）
├── build-apk.ps1     一键打包 APK 脚本
├── BUILD.md          APK 打包指南
└── android/          Android WebView 壳工程（Java，无第三方依赖）
```
